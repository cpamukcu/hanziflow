# HanziFlow Lessons + HSK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Lessons tab (photo lessons + built-in grammar/dialogue lessons) and HSK decks to HanziFlow, in HanziFlow's UI, with lesson words feeding HanziFlow flashcards.

**Architecture:** Pure logic in `js/lesson-core.js` (`window.HFLesson`, UMD like `sync.js`) ported from `chinese learning app/study/core.js` plus new pure helpers; HSK content in `data/hsk-content.js` (`window.HF_HSK`) generated by `tools/extract_hsk.mjs`; UI in `js/lessons.js`, a classic script loaded after `app.js` that uses app.js globals (`S`, `save`, `uid`, `esc`, `speak`, `colorHanzi`, `colorPinyin`, `hfDialog`, `toast`, `openWriter`, `go`, `newSRS`, `todayStr`, `HF`). Photo lessons live in `S.lessons` and sync like decks.

**Tech Stack:** Plain JS, Node tests (`node:test` / existing tiny runners), service worker stamped by `tools/stamp_sw.mjs`.

**Spec:** `docs/superpowers/specs/2026-11-18-lessons-and-hsk-design.md`

## Global Constraints

- Work on branch `lessons` in `~/Desktop/HanziFlow`; never push or merge without the learner's OK.
- Never change existing decks/cards/SRS data shapes; only add `S.lessons`.
- AI settings in `localStorage["hanziflow.ai"]`, lesson progress in `localStorage["hanziflow.lessonProgress"]` — never in `S`.
- AI-provided text reaches the DOM only through `esc()` or `textContent`.
- New app files go in both `sw.js` `SHELL` and `tools/stamp_sw.mjs` `FILES`; run `npm run stamp`; `npm test` must pass.
- Request rules from the study page stay: one request per lesson, ≤ 8 photos, resize to 1600 px JPEG 0.8, no `response_format`, `max_tokens` 8000, `readReply` for cut-off/empty.
- Default AI: OpenRouter `https://openrouter.ai/api/v1`, model `google/gemma-4-31b-it:free` (editable); presets `openrouter`, `custom`.
- Works at 375 px wide in light and dark theme.

## Review Focus

1. A lesson deleted on one device stays deleted after sync, and an edited lesson's newer copy wins (Task 2 tests).
2. Importing a backup made before this change (no `lessons` key) loads with `S.lessons = []` (Task 2 test via `normalizeState` behaviour — checked in browser in Task 6).
3. Adding an HSK deck when many words already exist only adds missing ones and reports the skip count (Task 3 `hskDeckPlan` test).
4. A built-in grammar point whose example words aren't in the dictionary still yields a playable lesson (Task 1 `builtinLesson` test with a stub lookup returning empty rows).
5. Six tabs fit at 375 px without overflow (Task 4 browser check, `scrollWidth === 375`).
